## 시작 가이드
### 필수 조건
- `Node.js` (버전 20 이상)
- `npm` (Node 패키지 매니저)
- VS Code 확장 프로그램: `Prettier` / `ESLint` (Prettier ESLint 같이 적혀있는 것 ❌)



### 설치
1. 레포지토리를 클론합니다.
```bash
  $ git clone https://github.com/prgrms-fe-devcourse/NFE1_2_3_Quote.git
  $ cd NFE1_2_3_Quote
```
2. 각 환경에서 필요한 패키지를 설치합니다. (`frontend`, `backend`)
```bash
  $ npm install
```
3. `.env` 파일을 생성하고 필요한 환경 변수를 설정합니다.
```bash
VITE_APP_CALLBACK_URL=
VITE_APP_SERVER_URL=
```


### 개발
프론트엔드 애플리케이션을 실행하려면 다음 명령어를 사용합니다.
```bash
  $ cd frontend
```
Local (frontend)
```bash
  $ npm run dev
```

## 주요 기능

### 🔍 회원가입 및 로그인

[이미지 첨부]

이메일 또는 카카오톡을 통해 회원가입 및 로그인이 가능합니다.

### 🔍 게시글 작성 

[이미지 첨부]

사용자는 인상깊었던 작품의 카테고리를 선택하고, 인상깊은 문장과 함께 자신의 생각과 느낌을 작성할 수 있습니다.

### 🔍 게시글 목록 및 카테고리 정렬

[이미지 첨부]

여러 사용자가 작성한 게시글을 카테고리별로 분류하여 확인할 수 있습니다.


### 🔍 작품 검색

[이미지 첨부]

궁금한 작품을 검색하여, 해당 작품에 관한 다른 사용자들의 게시글들을 확인할 수 있습니다.

### 🔍 북마크 및 댓글

[이미지 첨부]

인상 깊은 게시글에 북마크를 추가할 수 있으며, 다른 사용자의 게시글에 댓글을 남길 수 있습니다.

### 🔍 내 정보 관리

[이미지 첨부]

사용자는 자신이 작성한 글과 북마크한 글을 한곳에서 모아볼 수 있으며, 프로필 사진과 닉네임을 수정할 수 있습니다.

### 🔍 다크모드

[이미지 첨부]

라이트 모드와 다크 모드가 제공되어, 사용자는 선호하는 테마를 선택하여 사용할 수 있습니다.
